Sales Data Analysis Using Python

A beginner-friendly Data Analytics project using Python, Pandas, and Matplotlib.

Project Overview

This project analyses sample retail sales data to understand revenue, profit, product performance, city performance, and monthly sales trends.

Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab

Key Analysis

- Data cleaning
- Missing value handling
- Duplicate removal
- Revenue and profit calculation
- Product-wise sales analysis
- City-wise sales analysis
- Monthly revenue trends
- Data visualization

Dataset

The dataset contains synthetic sample retail sales records from January to June 2025. It is created for learning and portfolio purposes.
